OpenAlex 靠 UA 里的邮箱识别「礼貌池」，拿到更稳的速率。 另外它也是 Unpaywall 的必要参数：留空时「三级 OA 全文来源」里的 Unpaywall 那一级不会参与（实测空邮箱它直接返回 422），于是「找不到免费直链」 的概率会变高。填你自己的邮箱即可，一行字换回一路来源。
默认 文档\PaperPilotLibrary。会在此目录下建 literature\（PDF）与 vault\（Obsidian 笔记库）；不存在会自动创建。 点「📁 选择…」直接选文件夹，不用手打路径；保存后立即生效，已有的 PDF 不会自动搬过去。
专用浏览器（默认）：在你学校门户里登录一次，登录态长期留在 PaperPilot 自己的 目录里 —— 之后跑下载不用关掉你日常用的浏览器，也不限哪所学校。
借用日常浏览器：直接用你浏览器里已有的校园网 / 机构 cookie，但跑下载时 必须把 Edge / Chrome 完全关闭（含后台进程），否则调试端口起不来。
校园网内两种模式通常都按学校 IP 自动放行；在校外时点上面按钮登一次。 填了学校门户地址，那个按钮就会打开你学校的统一身份认证页， 而不只是 EBSCO。
机构全文通道用它打开你学校的 EBSCO 门户。校园网内通常按 IP 自动生效； 要手动登录时先点上面「打开 EBSCO 一次性登录」，登录后浏览器地址栏里 /c/ 后面那串就是 opid。留空则用安装包自带的值（朋友版默认为空，填了才启用机构通道）。
该通道是否符合你所在机构的订阅条款与当地法规，由你自行判断并承担后果； 本项目默认关闭。关闭时下载链会跳过这一环，只用开放获取 / 机构通道 / 出版商直链。
镜像域名常换，遇到新域名（如 mksa.top）自己加一行就行，不用等新版。 填了这里就只用你填的；留空恢复默认 sci-hub.ru, sci-hub.ee, sci-hub.se, sci-hub.st。 探测失败的镜像只降权/熔断 10 分钟、不会删除，域名恢复后自动重新启用。
部分页面需要看图定位下载入口，靠多模态模型完成。主模型若不支持读图， 这里单独指定一个视觉模型即可，不用改代码。
