# PaperPilot 软件作用与处理流程

> 版本 v1.4.0 · 本地文献工作台 · 完全自包含（不依赖任何 Agent/技能树，只要有 API Key 就能跑完全部功能）

---

## 一、软件作用

**PaperPilot 是什么**：一个跑在你本机的文献工作台。它把「找文献 → 判断值不值得读 → 下载官方 PDF → 精读做笔记 → 出推荐报告」这一整条科研文献工作流，压缩成几次点击。v1.5 起，**输入一段大白话研究意图即可全自动跑完全链（主题雷达）**。

**它解决什么问题**：
- 科研人每天要面对海量新论文，手工检索、筛选、下载、精读耗时巨大；
- 顶刊（TR 系列、INFORMS/UTD 系、IEEE 汇刊等）常被出版商付费墙挡住，直链下不动；
- 精读笔记格式不统一，散落在各处，难以检索和复用。

**PaperPilot 的答案**：
| 痛点 | PaperPilot 的做法 |
|---|---|
| 文献太多 | OpenAlex/Crossref/arXiv 全网检索，可勾选**仅顶刊池（22 刊）源头过滤**，LLM 五维打分排序 |
| 值不值得读 | LLM 按「相关/新颖/质量/方法/启发」五维打分，证据复核后才入选 |
| 下载难 | 多通道下载：OA 直下 → 浏览器借道 → **出版商页借道（IEEE 正式版主通道）** → EBSCO 机构通道（INFORMS/UTD/TR 系）→ ScienceDirect → 可选兜底通道（默认关闭）→ arXiv 预印本 |
| 精读费时 | 下载后**自动精读**，R1-R12（含 R8b，共 13 项）机器校验 + 独立外部复核，笔记直接进 Obsidian 库 |
| 报告整理 | 自动生成推荐报告、vault 卡片、去重历史 |

**顶刊池（22 刊，v1.5 扩容，ISSN 均经 OpenAlex 实测校验）**：
TR Part A/B/C/D/E · Transportation Science · Operations Research · Management Science · M&SOM · POM · INFORMS Journal on Computing · Mathematics of OR · Networks · EJOR · COR · OMEGA · IEEE TITS · IEEE TEVC · IEEE TASE · IEEE TCYB · IEEE IoT-J · IEEE TII。
清单在 `scripts/or-paper-radar/config/radar_profile.json`，增删一行即生效。

**期刊分层与 UTD 保底（v1.9）**：检索结果按四层加权排序——**UTD/旗舰**（Management Science、Operations Research、M&SOM、POM、IJOC、Mathematics of OR、Transportation Science，45 分）> TR 系（25）> IEEE 系（20）> OR 核心（EJOR/COR/OMEGA/Networks，15）。这 7 刊 UTD/旗舰产量低、标题学术化，在全库检索里容易被高产刊挤出，所以每次检索都会对它们**额外做一轮定向专项检索**保底；结果列表的期刊列会标注分层徽标。关键词相关度仍占主导：高度相关的普通刊不会被不相关的顶刊压过。

## 二、处理流程（核心全链）

```
用户输入研究方向（大白话研究意图 / 关键词）
      │
      ▼
① 提炼检索式（LLM，研究描述 → 2-5 个英文学术检索式）※主题雷达模式
      ▼
② 全网检索（OpenAlex 源头限定顶刊池 → 限流自动切 Crossref/arXiv）
      │  按主题自动归类、剔除库内已有
      ▼
③ LLM 五维打分（相关0.4 / 新颖0.2 / 质量0.15 / 方法0.15 / 启发0.10）
      │  达到阈值 + 证据复核通过才入选（待核条目不进交付清单）
      ▼
④ 多通道下载 PDF
      │  OA 直下 → 浏览器借道 → 出版商页(IEEE) → EBSCO → ScienceDirect → Sci-Hub → arXiv
      │  按 [年份]_[作者]_[题目].pdf 规范命名入库
      ▼
⑤ 自动精读（固定开启，不可关闭）
      │  note_writer 精读 + R1-R12 严格校验 + 独立外部复核
      │  有 FAIL 的不算成功（诚实标注，不假装通过）；单篇异常只损失该篇
      ▼
⑥ 出报告 + 上架（失败不影响已下载精读的成果）
        精读报告 / vault 卡片 / 去重历史 / 主题上架
```

### 每一步的细节

**① 提炼检索式（主题雷达）**
- 研究描述**长短不限**（几个字如「无人机」也行；超长段落只取学术信息、忽略背景叙述）→ LLM 提炼 4-8 个英文检索式 + 中文主题标签（v1.4 起宁多勿漏，多检多找）；
- 也可在「发现」页手动逐个检索或合并去重入池。

**② 检索**
- 勾选「仅顶刊池」（默认关）：OpenAlex filter `locations.source.issn` 源头限定 22 刊，省额度、候选准；
- 关闭后搜全库，顶刊仍打 ★ 且排序加权；
- 已入库的题名自动剔除（token 集合相似度 ≥85% 判重，防误伤）；
- OpenAlex 被限流时自动回退 Crossref + arXiv（回退候选同样打顶刊星标）。

**③ 打分**
- 每篇候选由 LLM 读摘要，按五维打分，权重固定；总分由软件按权重现算，不让模型自报；
- 证据复核通过（evidence_reviewed）且 ≥ 阈值才进下载名单；
- **待核条目（needs_verification）只记日志、不进交付清单**——v1.4 曾因此让收尾报告整批拒收、整个任务被误判失败，v1.5 已根治；
- 结果落盘 `data/reviewed_articles.json`。

**④ 下载**
- **先查库再下载**（v1.3）：逐篇先做库内查重——DOI 精确命中 > 题名整串相等 > 题名实词近似（Jaccard ≥0.85 且共享实词 ≥5，**并且库里真有这个 PDF**）；命中就跳过并计入「库内已有跳过」，绝不重下。检索阶段的剔除只走前两档（DOI/整串），近似题名不用于删候选——去掉停用词后 `with`/`without` 无法区分，悄悄删文献比留下更糟。
- 优先 OA 直下（不启动浏览器，快）；
- **出版商页借道**（v1.2 重写）：打开 DOI 落地页后**轮询「PDF 入口在不在」**（citation_pdf_url / IEEE 的 xplGlobal / arnumber），而不是等页面加载完毕；相对地址归一成绝对地址；取件统一走「会话 cookie 直下为主、页内 fetch 为兜底」，IEEE 的 stamp.jsp 壳自动剥 iframe。实测同一期刊（IEEE TITS）全部候选逐篇跑通，含 6 篇闭源正式版。
- 被出版商挡了 → 拉起浏览器调试会话「借道」真实身份。**v1.0.7 起默认用 PaperPilot 自己的
  持久 profile**：日常浏览器开着也起得了会话，机构登录在里面做一次就长期有效；
  想退回「直接借用你日常浏览器里的 cookie」可以把 `browser.mode` 切成 `real`，
  但那种模式下**必须先把 Edge/Chrome 完全关闭**（含后台进程），否则单实例锁会让
  调试端口起不来 —— v1.0.6 之前正是这里被误判成「没人用」而静默失败，
  表现就是「有的文献能下、有的下不到」；
- 白名单期刊（INFORMS/UTD 系 + TR 系列，14 条 ISSN 含双形态）→ 尝试 EBSCO 机构通道（需要机构网络权限；IEEE 通常不在 EBSCO，走其他通道）。**没填 opid 时这一级明确报「未配置机构门户」，不再拿空 id 拼坏 URL 白等一次超时**；
- 最后才走 ScienceDirect 通道；
- 以上都落空且手里有 DOI → 可选的兜底通道（**默认关闭**，需在设置里显式开启；镜像地址可自行
  配置，健康状态落盘、重启不忘）。是否启用该通道，取决于你所在机构的订阅条款与当地法规，
  由使用者自行判断并承担后果——本项目不内置任何账号、密钥或订阅权限；
- 幂等：同一篇已在库则跳过，不会产生 `_2` 副本；
- **失败可一键重试**（任务面板「↻ 重试失败 N 篇」）；最近一次下载落盘记忆，重启后仍可「精读上次下载」。

**⑤ 自动精读（产品默认行为，固定开启）**
- 任何下载任务完成后自动接精读，无需手动操作；
- 精读产出标准笔记（frontmatter + 摘要 + 核心发现 + 研究启发 + 证据锚），数学一律 `$...$` 行内渲染，**严禁杜撰**（原文没有的字段整行省略）；
- 写盘后**再独立跑一遍 R1-R12 复核**，有 FAIL 项就不算成功，结果面板如实显示每篇的 FAIL/WARN 明细；
- **单篇超时/异常只损失该篇**，批内其余照常完成（v1.5 加固）。

**⑥ 报告与上架**
- 自动生成 `radar-report.md`（TOP3 + 每篇评分分解 + 为什么值得读 + 核心发现 + 研究启发）；
- 笔记卡片写入 vault（Obsidian 可读）；
- 去重历史记录已推荐过的 DOI，避免重复推荐；
- **收尾失败不吞成果**：报告环节出问题时，已下载与精读的成果完好，任务面板给出重试入口（v1.5 加固）。

## 三、界面（两个标签页）

| 标签页 | 功能 |
|---|---|
| ⚡ **雷达** | 输入研究方向 → 找文献 → 勾选 → 下载并精读；🚀 全自动一键到底；任务面板（日志默认收起、出错自动展开）；最近调研；**导出 BibTeX / RIS** |
| 📚 **文库** | 搜已入库笔记（中英混用）、最近入库、主题过滤、⭐ 星标笔记、📚 主题书架管理（重命名/删除主题） |

右上角：🌙 深色模式 · 📋 运行日志（打包态排障）· 📄 关于（版本/库/Key 状态）· ⚙️ 设置（API Key / 模型 / 文献库位置 / 机构 opid / Sci-Hub 镜像与视觉模型）

**两个版本的首启体验**：我的专属版 Key 已内置、双击即用、无任何弹窗；朋友版首次打开弹欢迎引导，填一次 Key 后开箱即用（保存或点「稍后再说」后不再打扰）。

## 四、数据流与文件

| 文件 | 作用 |
|---|---|
| `settings.json` | API Key、模型、文献库路径（**不要外发**） |
| `data/queue.json` | 检索候选池 |
| `data/reviewed_articles.json` | 打分与入选结果（仅证据复核通过条目） |
| `data/radar-report.md` | 推荐报告 |
| `data/jobs.json` | 任务历史（重启可看、可重跑） |
| `data/last-downloads.json` | 最近一次下载（重启后可「精读上次下载」） |
| `data/scihub-mirrors.json` | Sci-Hub 镜像健康表（最近成功时间 / 连续失败数 / 熔断到期），重启不忘 |
| `文档\PaperPilotLibrary\literature\` | 下载的 PDF（可在设置里改到任意位置） |
| `文档\PaperPilotLibrary\vault\` | Obsidian 笔记库（精读产物） |

**安全边界**：
- 只允许本机访问（伪造 Host / 跨站 Origin 一律 403）；
- 星标只能作用于 vault 内笔记；主题名做注入校验；
- 批量改写前逐文件异常隔离并上报失败；
- 打包自检：脚本树含真实凭据（sk- 前缀 / 32+ 位 hex / AWS / GitHub PAT）直接中止打包，朋友版另做全包密钥扫描；
- 候选为空时不覆盖旧队列（防限流清空）。

## 五、常见问题

- **下载失败？** 任务日志会**逐条**列出每个通道的实际结局（无免费直链 / 找到直链但被挡 / 出版商页未找到 PDF 入口并给出最终落在哪个网址 / EBSCO 未命中原因 / 无对应预印本），可一键重试。
- **精读有 FAIL？** 结果面板显示 FAIL/WARN 明细，软件不会假装成功；可重跑该篇。
- **换电脑？** 整个文件夹拷走即可；文献库路径在设置里可改。
- **Key 安全？** 我的版 `settings.json` 含 Key，**绝不外发**；朋友版已剥离所有密钥。
