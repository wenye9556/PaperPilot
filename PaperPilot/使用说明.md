# PaperPilot 文献工作台 · 使用说明

> 本地文献工作台：**输入主题 → 自动检索顶刊 → 下载正版 PDF → 自动精读 → 调研报告**，一条龙。
> **完全自包含**：不依赖任何账号体系/Agent 环境。

## 🚀 怎么启动

### 第 0 步：先看清楚 exe 在哪一层

压缩包解开后是**两层**文件夹，exe 在里层：

```
PaperPilot_V2\            ← 解压工具自动建的文件夹（通常以压缩包命名）
└── PaperPilot\           ← 软件本体。要搬家就整个这一层一起搬
    ├── PaperPilot.exe    ← 双击这个
    ├── _internal\        ← 必须和 exe 待在一起，千万别只拷 exe
    └── 使用说明.md
```

⚠️ **不要只把 `PaperPilot.exe` 单独拖出来**——`_internal\` 是它的运行库，
少了就启动失败。要换位置请**整个 `PaperPilot` 文件夹一起移动**。
路径里有中文、有空格都没关系。

### 第 1 步：双击 `PaperPilot.exe`

会弹出一个**确认框**：告诉你服务已经启动、界面地址是什么，并问「现在打开界面吗？」。

- 点 **「是」** → 自动帮你打开浏览器进界面
- 点 **「否」** → 让它安静地在后台跑，你自己稍后开浏览器访问
- 直接把框关掉 → 也可以，服务照样在跑

> **看到这个框就说明启动成功了。** 如果**完全没有任何反应**，那才是真出问题了——
> 先确认 `_internal\` 文件夹在不在 exe 旁边。

### 第 2 步：访问界面

浏览器打开 <http://127.0.0.1:8734> 即可。不确定地址时，看 exe 同目录下的
`data\addr.txt`，里面写着本次的真实地址（端口被占用时会顺延，这个文件也会跟着更新）。

⚠️ 不要直接双击文件夹里的网页文件（`web/index.html`）——那样打不开后端，页面会提示你回到 exe。

### 可选：改启动行为

| 想要的效果 | 怎么做 |
|---|---|
| 启动时自动开浏览器（不用点「是」） | 启动前 `set PAPERPILOT_OPEN_BROWSER=1` |
| 完全静默，连确认框都不要 | 启动前 `set PAPERPILOT_SILENT=1` |
| 停止服务 | 任务管理器里结束 `PaperPilot.exe`；关掉浏览器**不会**停止服务 |

### 忘记关了、又双击了一次？

会提示「PaperPilot 已在运行」，并问你要不要打开界面——点「是」即可。
**不会**起出第二个实例来抢端口。

## 🎯 三分钟上手：找文献 → 挑 → 下载精读

首页输入研究方向（几个字也行，相关的也能搜到）→ 点 **🔍 找文献** → 列表里勾选想读的（或点 **🤖 LLM 挑选** 自动勾选值得读的）→ 点 **⬇️ 下载并精读**。任务面板逐篇显示论文名称/期刊/状态（下载通道、精读 R1-R12 结果）。

默认**全库检索**（结果多，顶刊打★排前）；勾选「仅顶刊池」则只在 22 刊顶刊里找。点 **🚀 全自动** 可跳过挑选（打分→下载→精读→报告一气呵成，约 10 分钟，按篇数消耗 API 额度）。

**导出引用**：列表右上角「导出 BibTeX」/「RIS」——优先导已勾选的（一个没勾就导当前列表全部）。
作者、卷期页、页码会按 DOI 从 Crossref 自动补齐，EndNote / Zotero / NoteExpress 可直接导入。

## 🔑 两个版本的差别

| | 我的专属版 | 朋友分发版 |
|---|---|---|
| API Key | **已内置，双击即用，不会弹窗要 Key** | 首次打开弹欢迎引导，填一次你自己的 Key（OpenAI 兼容接口均可），保存后不再打扰 |
| 分发 | `settings.json` 含个人 Key，**绝不外发** | 已剥离全部密钥并通过扫描校验，可放心拷给朋友 |

朋友版首次配置项（**全部在界面里填，改完点「保存设置」立即生效；不填的项按下面的默认值走**）：

| 项 | 填什么 |
|---|---|
| **API Key** | 你的 OpenAI 兼容接口 Key（例如 `sk-...`）。**不填也能用检索/下载/入库**，只是「打分排序」和「精读笔记」用不了 |
| **Base URL** | 你的接口完整地址，例如 `https://你的接口域名/v1/chat/completions`（忘写 `https://` 也没关系，软件会自动补全） |
| **模型** | 填好 Key 和 Base URL 后点模型框旁的 **🔄**，自动列出这家接口可用的全部模型，下拉选择即可，不用猜（个别接口不开放列表时也可手输） |
| **文献库位置** | 下载的 PDF 与笔记放哪。默认 `文档\PaperPilotLibrary`；点 **📁 选择…** 弹出系统选择框，**可以自由浏览任意盘符、网络位置**，也可以直接把路径粘进地址栏。旁边「打开」定位当前目录，「默认」恢复默认值。⚠️ 改位置后**已有的 PDF 不会自动搬过去**，需要你自己复制 |
| **OpenAlex API Key（可选）** | 免费申请：`POST https://api.openalex.org/api-keys {"email":"你的邮箱"}`，点邮件激活。填了每天 $1 独立额度 |
| **机构门户 opid（可选）** | 你所在学校/机构的 EBSCO 门户标识。填了才能用「机构通道」下载；不填不影响开放获取通道 |
| **Sci-Hub 兜底（可选，**默认关闭**）** | 只在开放获取/机构通道/出版商直链都拿不到时才用。请在「设置 → 高级」自行勾选开启，并自行确认当地合规性 |

填完点「保存并开始」，可先「测试连接」验证。

> **不想用界面配大模型密钥？** 也可以复制 `config.local.example.toml` 为 `config.local.toml`
> 后编辑，适合脚本化部署。注意**界面设置的优先级更高**。

> **关于「主题雷达」的关键词**：随包的检索画像里**不预置任何人的研究方向**，
> 你第一次用直接在雷达页的输入框写自己的方向即可（几个字也行）。
> 这样既不会误抓别人关心的论文，也不会漏掉你真正要的。

## 📑 两个标签页

| 标签 | 用途 |
|---|---|
| **⚡ 雷达** | 🎯 主题雷达一键到底；或关键词/研究描述模式手动检索，自动剔除库内已有、按主题归类、标记顶刊 ★。勾选结果后可下载/精读，或直接「全自动」跑完全链 |
| **📚 文库** | 搜索你已入库的笔记（中英文）、最近入库、⭐ 星标、📚 主题书架管理 |

## ⚡ 关键行为（默认开启）

- **下载后自动精读**：任何下载完成自动接精读（R1-R12 严格校验 + 独立外部复核），无需手动。
- **LLM 五维打分**：相关 0.40 / 新颖 0.20 / 质量 0.15 / 方法 0.15 / 启发 0.10；证据复核通过且 ≥ 阈值才下载，**摘要撑不住的宁可不推**。
- **仅顶刊池（默认关）**：默认搜全库、给顶刊打 ★；勾选「仅顶刊池」后检索源头就限定 22 刊（见下），候选少而精。
- **多通道下载自动判断**，逐级递进、每级结局都写进日志：OA 免费直链直下（免开浏览器）→ 同一链接借浏览器身份取 → **出版商页借道**（打开 DOI 落地页找 PDF 入口，IEEE 正式版走这条）→ EBSCO 机构通道（INFORMS/UTD/TR 系白名单，需机构权限）→ ScienceDirect 通道 → arXiv 预印本兜底（Sci-Hub 默认关，需在设置里开启）。
- **任务可随时停止**：任务面板右上角「⏹ 停止」——当前这篇 / 这一阶段做完就停，已完成的下载与精读**全部保留**，剩余可稍后从「最近调研」重跑补齐（v1.4）。
- **下载用的浏览器页面自动收走**：整个批次只复用一个工作标签（不再每篇弹一个页面），批次结束自动关闭本次打开的页面、浏览器随之退出；机构登录态存在专用 profile 里，下次免登（v1.4）。
- **顶刊池（22 刊）**：TR Part A/B/C/D/E · Transportation Science · Operations Research · Management Science · M&SOM · POM · IJOC · Mathematics of OR · Networks · EJOR · COR · OMEGA · IEEE TITS/TEVC/TASE/TCYB/IoT-J/TII。清单在 `scripts/or-paper-radar/config/radar_profile.json`，可自行增删。
- **库里有的不再重复下载**：下载前按 **DOI** 认出同一篇（题名会变，DOI 不会），其次比题名；刚下完还没精读的也会记进 `data\doi-index.json`，下一批碰到同一篇直接跳过。结果列表里会标 **📚已有**，下载汇总写成 `库内已有跳过 N（同名 a · 按 DOI b · 题名近似 c）`。
- **候选只收论文本体**：检索阶段就剔掉审稿意见（"Review for …"/"Decision letter for …"）、数据集、目录页、撤稿声明这类同刊同名的非论文条目——它们勾上必然下不到，以前正是「同一本期刊这篇能下那篇下不到」里最迷惑的一种。
- **摘要中英预览**：结果列表点任意一行，展开英文摘要 + 中文翻译（自动懒加载）。
- **IEEE 正式版**：机构网下经「出版商页借道」直接取 IEEE Xplore 正式版 PDF（v1.8 上线；v1.2 起改为「等 PDF 入口出现」而不是「等页面加载完」，SPA 慢页面不再误判成超时，实测同一期刊全候选逐篇跑通）。

## ❓ 常见问题

- **双击 exe 完全没反应？** 正常情况下**一定会弹一个确认框**（告诉你已启动、并问要不要开界面）。
  如果真的一点动静都没有：
  1. 先看 `_internal\` 文件夹在不在 exe 旁边 —— 只拷了 exe 出来就会这样，把整个
     `PaperPilot` 文件夹一起拷回来；
  2. 看任务管理器里有没有 `PaperPilot.exe` —— 有的话说明其实在跑，直接访问
     <http://127.0.0.1:8734>；
  3. 还是不行就双击 `使用说明.md` 旁边的 `data\paperpilot.log`，看最后的报错。
- **双击 exe 又被「已在运行」挡掉？** 说明后台已经有一个实例占着 8734。
  按提示点「是」打开界面即可；要彻底重启就先在任务管理器里结束 `PaperPilot.exe` 再启动。
- **下载的 PDF 存到哪里了？** 默认存在**「文档」文件夹下的 `PaperPilotLibrary\literature`**
  （例如 `C:\Users\你的名字\Documents\PaperPilotLibrary\literature`），笔记库在同一个目录下的 `vault\`。
  这个目录**首次运行会自动创建**，不需要提前准备。下载完成后任务日志里会明确打出
  「PDF 保存位置：…」一行，界面上也会显示同一个路径并带一个**「打开文件夹」按钮**，
  点一下就直接跳到那里。
- **想把 PDF 存到别的地方（比如 D 盘）？** 打开**设置 → 文献库位置**：
  - 点 **「📁 选择…」** 会弹出 Windows 标准的文件夹选择框：**带地址栏，可以直接把路径粘进去**，
    左侧导航栏也能自由跳到任意盘符、U 盘、网络位置（推荐，不用手打路径）；
  - 或直接在输入框里填路径，例如 `D:\论文`；
  - 点 **「保存设置」** 后立即生效，软件会自动在该目录下建 `literature\` 与 `vault\`。
  - 想改回默认位置，点 **「默认」** 按钮即可。
  - ⚠️ 换位置后，**之前下载的 PDF 不会自动搬过去**，需要你手动剪切到新目录。
  - **「打开」** 按钮可以直接在资源管理器里打开当前 PDF 目录。
  - 填了打不开、或路径不存在时，软件会明确报错告诉你原因，不会静默失败。
- **下载失败？** 看任务面板日志：会**逐条**列出每个通道的实际结局（OA 无直链 / 出版商页未取到 / EBSCO 未配置 / ScienceDirect 需登录 / 无 arXiv 版本），一眼看出断在哪一环，可一键重试，不假装成功。
- **付费墙的论文下不到？** v1.0.7 起浏览器通道默认用 **PaperPilot 自己的专用目录**，
  所以**不用再把 Edge / Chrome 关掉**了（任务日志里会写「使用 PaperPilot 专用 profile…
  你的日常浏览器此刻正开着 —— 与本次下载无关」）。代价是要在里面登一次：
  - **在校园网内**：通常不用做任何事，出版商按你学校的出口 IP 自动放行；
  - **在校外 / IP 不被识别**：打开 **设置 → 🎓 打开机构登录窗口**，在弹出来的那个
    PaperPilot 窗口里用你学校的账号登录一次。登录态存在专用目录里，**之后一直有效**，
    不用每次登。建议顺手把「学校图书馆门户地址」填成你自己学校的统一认证页，
    这样那个按钮打开的就是你学校的登录页，而不只是 EBSCO。
  - 想改回旧行为（直接借用你日常浏览器里已有的 cookie）：把模式切到「借用我日常浏览器的
    登录态」—— 那样跑下载**必须先把 Edge/Chrome 完全关闭**（含后台进程），否则调试端口起不来。
- **为什么需要登录？我之前手动能下啊？** 因为权限本来就在「你学校的身份」上。旧版本是去
  **借**你日常浏览器里的身份，所以一开着浏览器就借不到（v1.0.6 及之前更糟：它误判成"没人用"，
  静默失败，表现就是「有的文献能下、有的下不到」）；现在改成**软件自己存一份身份**，
  你登一次就行，不再依赖你浏览器开没开着。
- **日志出现「浏览器未就绪，剩下那些只能靠 OA 直下」？** 说明这一批里需要浏览器的通道
  （Edge 借道 / 出版商页 / ScienceDirect）都没启动。先看上面 `[浏览器]` 那几行的原因，
  再用「↻ 重试失败 N 篇」重跑。
- **软件用的是哪个浏览器？** 自动探测：装了就优先用 Edge，只有 Chrome 也一样能用（v1.0.0 曾硬编码 Edge，机器上只有 Chrome 会失效，v1.0.1 已修）。
- **API Key 填错了？** 设置里改一下立即生效；Key 存在 exe 同目录 `settings.json`，**不要把这个文件发给别人**。
- **换电脑？** 整个文件夹拷走即可；文献库默认建在「文档\PaperPilotLibrary」（设置里可改，PDF 与笔记都在里面）。
- **精读有 FAIL？** 结果面板显示每篇 FAIL/WARN 明细，软件不假装成功；可重跑该篇。
- **精读报错「退出码 5」？** 多半是模型没配好（Base URL / API Key / 模型名）。任务日志（出错会自动展开）里会写具体原因：`[LLM 未配置]` = 没填 Key；`401/403` = Key 或端点不对；`429` = 撞限流。
- **精读报错「almost no text layer」？** 那是扫描版 PDF（整页是图片、没有文字层），软件不会去硬读。换有文字层的版本，或先用 OCR 处理。
- **弹出「Failed to execute script 'app'」+ `paper_tool` 字样？** 这是 v1.9.6 及更早版本的已知问题：读 PDF 时优先调用系统里的 `pdftotext`（poppler），你的电脑上没装就直接崩了。**v1.0.0 起已修**——找不到 `pdftotext` 会自动改用内置的 PyMuPDF，无需另装任何东西。
- **兜底通道怎么开？** 设置里勾选「启用 Sci-Hub 兜底通道」才生效（默认关闭）；镜像换了就在下面填新域名（逗号或换行分隔，留空=默认四个），保存即生效，不用等新版。
- **机构全文通道用不了？** 校园网内通常按 IP 自动生效；校外时先在设置里点「🎓 打开 EBSCO 一次性登录」用学校账号登一次。若仍不行，把「机构门户 opid」填成你自己学校的门户 id（登录后浏览器地址栏 `/c/` 后面那串），保存即生效。
